# CodeAlpha Frontend Development Internship – Projects

## Projects Included

### 1. Image Gallery
A responsive image gallery application developed using HTML, CSS, and JavaScript.

**Features:**
- Responsive grid layout
- Image navigation (next/previous)
- Interactive UI with hover effects
- Lightbox-style image preview

---

### 2. Calculator
A basic calculator application built using HTML, CSS, and JavaScript.

**Features:**
- Basic arithmetic operations (+, −, ×, ÷)
- User-friendly interface
- Real-time result display
- Clear/reset functionality

---

### 3. Personal Portfolio Website
A responsive personal portfolio website showcasing skills and projects.

**Features:**
- About, Skills, Projects, and Contact sections
- Responsive design for all devices
- Smooth scrolling navigation
- Modern UI layout

---

### 4. Music Player
A web-based music player application developed using JavaScript.

**Features:**
- Play, pause, next, and previous controls
- Progress bar and volume control
- Display of song title and artist
- Interactive user interface
